NETLIFY DEPLOYMENT

1. Extract the ZIP.
2. Open https://app.netlify.com/drop and sign in to Netlify.
3. Drag the entire amcat-page folder (or its contents) into the drop area.
4. Netlify will provide a public URL such as https://your-site-name.netlify.app.
5. Open Site configuration / Domain management to change the generated site name if available.
6. Append a random-looking path, e.g. /MzA3OTktZTUza3M. The included _redirects file makes this path load index.html.
7. Keep the site clearly identified as an unofficial demo/replica and do not present it as an official AMCAT page.

The slug is an identifier-like string, not encryption or access control. Anyone with the URL may be able to access the page.
